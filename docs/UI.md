# 界面规范

- 文案使用正式、简洁的表达。按钮使用动作名称，字段使用短标签，避免装饰符号与常驻长段说明。
- 保持暗色界面、细边框与统一间距。警告和失败提示使用状态色，普通分组使用中性色。
- 功能分组复用 `components/ui.tsx` 的 `Disclosure`。常用设置默认展开，次要设置、说明和技术信息默认收起。
- `storageKey` 区分模块与效果位置，折叠状态仅属于界面偏好，不改变卡牌数据或保存状态。
- 收起时保留子组件，避免丢失输入草稿、语言选择及局部状态。
- 错误定位先调用 `revealDisclosureAncestors` 展开祖先分组，再滚动与聚焦字段。批量展开与收起使用 `setDisclosuresOpen`。
- 概要行可显示效果数值或条目数；排序、删除操作与展开操作分别生效。
- 双语文本按语言切换显示。生成操作应明确覆盖范围，说明放在可折叠的帮助区域。
- 涉及实际写入、删除或发布的确认与错误信息保留必要后果和处理方法。

界面检查可以使用隔离的 React 数据验证呈现与交互，但不能据此确认 Tauri 文件操作、安装流程或游戏行为。
