日期：2026-11-13。当前发布 Editor 0.4.3，Runtime 0.2.2。

0.4.3 补充安全加固与资源预算，兼容性机制沿用本页记录。

0.4.2补充：愚者已加入默认官方卡池列表。首次选择会自动保存所需定义，原有扩展池标识保持兼容。

## 目标版本与来源

本机游戏目录为 `E:\SteamLibrary\steamapps\common\Slay the Spire 2`。
Steam 分支为 `public-beta`，Build ID 为 `26625880`；`release_info.json` 为 `v0.113.0`，提交 `16ac0fe3`。

[官方 v0.113.0 公告](https://steamcommunity.com/app/2868840/announcements/?l=english)列出新角色 The Fool 与 Blitz、Dread 模式。本次适配以本机实际程序集为依据。

## 完成的适配

1. 新增原版卡池自动使用 `mod:sts2:<完整类型名>` 引用，并绑定游戏程序集；既有八种卡池键保持兼容。Fool 及后续原版角色复用这条路径。
2. 新原版卡的目录导出、复制导入、项目卡池定义和发布依赖保持一致。使用扩展原版池的卡包要求 Runtime 0.2.1；原版身份与第三方工坊依赖分别处理。
3. 游戏内容入口默认显示全部来源，显示快照的实际游戏版本。游戏或运行组件文件更新后，旧快照会提供刷新提示。
4. 状态、敌人和生成卡牌选择优先使用当前游戏导出数据，保留离线目录作为缺失条目的回落。内置原版目录仍是单独的离线入口。
5. 界面恢复重构前的蓝黑、琥珀、天蓝与绿色配色，以及原卡面光晕；中央编辑区、结构导航和草稿机制沿用0.4.0。

## 使用步骤

1. 退出游戏，解压并打开新版 `editor.exe`，确认项目设置中的游戏目录。
2. 编辑器会更新内置运行组件。启动游戏并启用 SpireForge Runtime，进入主菜单完成目录导出。
3. 返回编辑器，打开「导入与素材 → 当前游戏内容」，点击「刷新」。核对快照版本为 v0.113.0、Runtime 为0.2.1。
4. 新建愚者卡牌时，直接在「卡牌信息 → 卡池」选择「愚者」。第三方及其他扩展卡池通过「角色卡池 → 从游戏读取」添加。
5. 原版卡修改可通过当前游戏内容导入，选择「修改原卡 · 保留原行为」。新卡的效果在「效果与规则」中配置。
6. 安装一个测试卡包，分别检查卡牌注册、基础效果、状态联动和选牌。Blitz、Dread 单独进行实战验收。

状态草稿在本次应用使用期间保留，关闭前点击「保存状态」写入卡包。

## 后续游戏升级

从仓库根目录运行：

```powershell
node tools/game-compatibility/run.mjs --game-dir "E:\SteamLibrary\steamapps\common\Slay the Spire 2" --output "D:\spireforge\work\compatibility\next-update.json"
```

工具记录真实版本、Steam分支、程序集SHA-256、关键API签名、枚举及卡池清单，输出位于项目工作目录。若接口发生变化，优先修复Runtime适配层，再运行规则回归、更新目录和游戏验收。

工具与模块的边界见 [游戏兼容性检查工具](../tools/game-compatibility/README.md)、[界面规范](UI.md) 和 [Runtime手册](RUNTIME-MOD.md)。本项目沿用现有Skill与MCP，周期性版本适配由项目工具承接。
