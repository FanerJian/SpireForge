# 规则编辑指南

适用版本：SpireForge 0.4.0，Runtime 0.2.0。

## 从一个例子开始

1. 打开卡包并选择一张卡。
2. 进入「效果与规则」，点击「添加规则组合」。
3. 点击「专注编辑」，在完整工作区设计规则。
4. 进入「模板」，预览一个例子，点击「添加此模板」。
5. 修改规则块中的数值、条件或目标，返回面板后点击「生成描述」。
6. 通过「发布 / 安装」检查并生成卡包，进入游戏试玩。

每个规则块都提供启用、上移、下移、复制和删除。条件分支分别编辑「满足时」与「否则」的动作；重复和随机节点可以包含多条规则。工作台与中央编辑区共用同一份编辑内容。左侧结构导航可直接定位嵌套分支。

## 五个组合模板

| 模板 | 可以观察到的机制 |
|---|---|
| 易伤追击 | 先造成8点伤害；目标拥有易伤时追加4点伤害并抽1张牌，否则施加2层易伤。 |
| 格挡转伤害 | 伤害读取当前格挡，适合设计防御流派的终结牌。 |
| 三次连击 | 执行规则时增加本回合 `combo` 计数；累计3次后抽牌并归零。参与联动的卡使用相同计数器标识。 |
| 回收攻击牌 | 从弃牌堆选择1张攻击牌，移入手牌，费用在本回合降低1。 |
| 星火状态 | 给目标施加3层星火；拥有者回合结束时按层数造成伤害，再衰减1层。 |

在「模板」中展开「保存为模板」，填写名称并保存。之后可在当前卡包的其他卡牌中继续使用。

## 动态数值

把「固定数值」切换为生命、格挡、牌堆张数等来源。展开「数值计算」可设置乘数、加减值、取整方式及上下限。

例如读取「已损失生命」，乘数设为0.5、向下取整，即可制作按已损生命一半获得格挡的效果。

计数器有本回合和本场战斗两种范围。相同卡包、相同玩家、相同标识共享计数，范围变化后按对应生命周期读取。读取状态时，「当前目标合计」表示目标集合的总层数。

全体目标规则整体执行一次：默认伤害和状态作用于目标集合，抽牌和计数器各执行一次。卡牌本身为X费时，仍沿用整段效果按X值展开的既有规则。

## 自己定义状态

在「自定义状态」中新建状态，填写名称、说明并设置触发时机与规则。点击「保存并引用」，即可保存状态并将它加入当前卡牌规则。状态标识自动分配，图标、翻译和层数限制可按需展开。

读取状态层数时，按名称搜索选择状态。计数器支持搜索复用或直接输入名称新建。状态草稿在本次应用使用期间按卡包保留，切换卡牌或编辑页后可继续；关闭应用前点击「保存状态」。

- 相同状态标识供卡包内多张卡共同施加和消耗。
- 叠层方式可选择累加、替换或取较大值；层数上限单独设置。
- 触发时机可选择拥有者回合开始、回合结束、打出卡牌后或攻击完成后。
- 拥有者回合结束时按衰减值减层；设为0可保持层数。
- 每回合触发上限用于控制连续联动。状态的持续范围为当前战斗。
- 触发规则中的当前目标为状态拥有者，来源卡为首次施加该状态的卡。

共享定义保存后，导出和打包采用最新定义。单卡导出也携带可移植状态快照，便于传给其他项目。

## 选牌与牌堆操作

添加「选牌与操作」，先选来源牌堆、选择方式和类型筛选，再按顺序增加操作。

例如「移动到手牌 → 本回合费用降低1」，会先将所选卡移入手牌，再调整该卡费用。复制操作后，后续操作作用于新副本。玩家选择使用游戏原生选择界面，随机选择沿用游戏随机源。

费用增减适用于普通费用卡；X费及游戏不可打出费用沿用游戏费用模型。

## 保存与检查

编辑中的空条件分支和待填写引用可以作为草稿保存；发布检查会定位需要补充的字段。
规则节点最多256项，包含使用的状态规则。嵌套最多8层，单次展开最多100次。编辑器与Runtime共享契约校验和执行预算。
生成说明后可在「文案」页调整措辞。再次生成时会对已有文字发起覆盖确认。

开发者可运行 `node tools/make-rule-examples.cjs <新的输出目录>` 生成独立的五卡示例项目。契约及扩展入口见 [RULES.md](RULES.md)。
